# Bài 1 - Trang hồ sơ

Cài đặt và chạy:
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
flask --app app run --debug
```
Mở http://127.0.0.1:5000.

Trang hồ sơ dùng biến, vòng lặp và thẻ HTML từ template.
