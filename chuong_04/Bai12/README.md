# Bài 12 - Menu đánh dấu trang hiện tại

Cài đặt và chạy:
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
flask --app app run --debug
```
Mở http://127.0.0.1:5000.

Biến active được truyền từ route và dùng điều kiện Jinja2 để đánh dấu menu hiện tại.
