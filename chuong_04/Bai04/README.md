# Bài 4 - Dự đoán kết quả filter

Cài đặt và chạy:
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements.txt
flask --app app run --debug
```
Mở http://127.0.0.1:5000.

Bảng minh họa các filter thường dùng. Kết quả được tính sẵn để người học đối chiếu.
